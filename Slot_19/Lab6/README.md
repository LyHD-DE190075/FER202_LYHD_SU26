# Lab 06 — Redux Toolkit trong ReactJS

App React + Vite dùng Redux Toolkit với 3 tính năng: Counter, Todos, Posts (async).

## Chạy project

```bash
npm install
npm run dev
```

Mở http://localhost:5173

## Build

```bash
npm run build
```
